01 · Hardware
IoT & embedded systems · team project, 4 members

Smart Dustbin

A touchless, IoT-connected waste bin: an IR sensor opens the lid automatically, an ultrasonic sensor tracks fill level, and Blynk streams it all to a live dashboard. My part was the Blynk setup end to end.

ESP32 HC-SR04 ultrasonic IR sensor SG90 servo Blynk IoT
My part: Blynk setup

Configured the three datastreams the ESP32 reports to — V0 distance (cm), V1 bin level (%), V2 servo angle — and set up the "bin full notification" event, triggered at 85% capacity and delivered to the device owner by both email and push notification, plus the live web dashboard used to monitor all three readings in real time.

How the system behaves

Approaching the bin triggers the lid open via the IR sensor; it holds for 3 seconds, then closes automatically. The ultrasonic sensor continuously recalculates fill percentage so the dashboard and notifications stay current without any manual check.

Challenges

Ultrasonic readings fluctuated with irregular waste surfaces, the servo needed power-supply tuning for stable movement, and Wi-Fi drops occasionally delayed dashboard updates — all addressed before the final build.

the-internet.herokuapp.com — 8 test cases

A unittest-based suite covering login (valid, invalid, and empty-field cases), logout, checkboxes, dropdown selection, dynamic content loading, and homepage navigation — each with explicit waits instead of fixed sleeps, so tests don't fail on slow page loads.

TC001 valid login TC002 invalid login TC003 logout TC004 checkboxes TC005 dropdown TC006 dynamic loading TC007 empty login TC008 nav links 
def test_TC001_valid_login(self):
    self.driver.get(f"{self.base_url}/login")
    self.wait.until(EC.presence_of_element_located((By.ID, "username")))

    self.driver.find_element(By.ID, "username").send_keys("tomsmith")
    self.driver.find_element(By.ID, "password").send_keys("SuperSecretPassword!")
    self.driver.find_element(By.CSS_SELECTOR, "button[type='submit']").click()

    success_msg = self.wait.until(
        EC.presence_of_element_located((By.CSS_SELECTOR, "#flash.success"))
    )
    self.assertIn("You logged into a secure area", success_msg.text)
